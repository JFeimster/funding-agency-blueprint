RECIPE / PROPOSED

01 / New application → CRM

Form submission → consent check → CRM record → owner assignment → acknowledgment. Avoid duplicate creates and log event IDs.

RECIPE / PROPOSED

02 / Missing documents → follow-up

A human-approved document checklist triggers a permission-aware reminder. Do not email private applicant documents.

RECIPE / PROPOSED

03 / Partner criteria → review queue

Monitor verified program changes → flag a record → human verifies → update partner-fit matrix.

RECIPE / PROPOSED

04 / Edition → companion resource

Publish verified issue → link tools, guide and downloads → measure clicks and resource engagement.
